# Introducción

Durante el desarrollo del proyecto HelpDesk Flow se aplicaron prácticas ágiles como Kanban para organizar el trabajo entre los integrantes del equipo. Además, se utilizó GitHub para el control de versiones y herramientas de Inteligencia Artificial como apoyo durante el diseño, implementación y documentación del sistema.

Esta retrospectiva resume la experiencia obtenida durante el desarrollo del proyecto, identificando los aspectos positivos, las dificultades encontradas y las oportunidades de mejora.
